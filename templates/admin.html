Édition en masse

Le LaTeX s'écrit directement dans les textes entre $...$ ; en JSON, chaque antislash est doublé (\\frac{1}{2}). Les images utilisent le champ image (URL https publique). L’ancien champ image_complete est converti en image à l’enregistrement. Le champ optionnel explication s'affiche à tous à la révélation de la réponse et dans le récap des erreurs.
Pour supprimer un chapitre en conservant ses questions, utilise « Supprimer le chapitre » dans la liste des chapitres.

Enregistrer valide automatiquement toutes les questions. En cas d’erreur, la banque reste inchangée et tes modifications restent disponibles pour correction.

Les images doivent être sur une URL publique (ex : imgur).

Tester une question QCM

Colle un JSON de test, puis vérifie exactement son rendu avant de l’ajouter aux questions réelles. Ce test ne modifie rien.

Cet espace ne sauvegarde rien. Utilise uniquement image pour une image. Les commandes LaTeX ont deux antislashs dans le JSON : \\frac, \\sqrt, \\int.

Bordure verte : bonne réponse configurée. Ce rendu est une prévisualisation : il n’y a pas de chrono ni de score.
